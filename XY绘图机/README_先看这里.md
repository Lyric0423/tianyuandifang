# 第二次作业：XY 绘图机

选用方案一。普通纸固定，两个步进电机驱动 XY，SG90 只抬笔。默认画直径 **80 mm** 的圆与边长 **50 mm** 的正方形，中心相同。实际加工零件共 **19 件**（含一件试切片）；准确数量和边界以 `图纸/图纸检查报告.json` 为准。

这是一套可加工、可调试的原型设计文件，尚未在你的实物上完成试装。正式切割前请按下面的尺寸核对表检查电机、笔和槽宽。软件仿真不代表实物精度或一定不会丢步。

## 切割前核对

1. 步进电机应是课件中五线、5V、28BYJ-48 这一类，配 ULN2003 板。设计初值为安装耳孔距35 mm、轴相对壳体中心偏8 mm。安装长孔可微调；若实物型号不同，请先改图。
2. 齿轮外轮廓直接沿用老师的 `Gear+Bar.dxf`，不是重新画的近似齿轮。16齿、齿条节距4 mm，每转名义推进64 mm。齿条保留参考齿形，只缩短长度、加宽背板。
3. 齿轮中孔保留参考文件的 **双扁孔4.8×2.8 mm**。先用Q1的三种双扁孔核对实轴，不能把它随意替换成圆孔。若选用其他规格，两个齿轮孔也要同步修改，不能只改Q1。
4. 导向槽名义宽3.30 mm，配M3螺杆；实际槽宽会受切缝影响。Q1有3.1/3.3/3.5三档。需要滑动、不明显横向摇晃。
5. 板厚按 **2.75 mm** 初排装配高度；有的课件写2.85 mm，实际以老师测量为准。这里用螺母、垫片和胶带调间隙，不使用按固定板厚硬卡的榫卯。
6. 默认笔身直径8 mm，下导向孔和上导向孔均为8.4 mm。先实测笔身；若只用细笔芯，可套胶带形成直径均匀的导向套。改笔径时同时调整D2/D3。

这次只有两次加工机会。第一轮图里已放入Q1，装配后集中记录要改的孔和槽，第二轮再统一修正；不要在没有核对轴孔和槽宽的情况下认定文件可以直接达到最终精度。

## 最短运行流程

1. 按 `装配与调试.md` 装机械，先断电检查全行程；按接线图接两个驱动板和舵机。电机/舵机用稳定外接5V，ESP32用USB，所有GND共地。
2. 用Thonny把 `config.py`、`geometry.py`、`plotter.py`、`main.py` 上传到设备根目录，再运行 `main.py`。启动会给舵机“抬笔”指令，但不会自动移动XY。
3. 先不连舵盘与笔环，调 `servo 1200`、`servo 1600`，确认方向与摆幅，改 `config.py` 的抬笔/落笔值后再连好。
4. `jog x 5`、`jog y 5` 核对方向。相反就修改对应 `*_DIRECTION`；不要交换整个XY机械定义。
5. 在绘图开始前定位笔尖原点，输入 `zero YES`。**这只是声明当前坐标，不是自动找原点。**
6. `cal x`、`cal y` 各画50 mm线，按实测修正steps/mm。然后 `dry` 全程抬笔空走。
7. 空走结束后电机已释放，按说明重新确认原点，再 `zero YES`，最后 `draw`。录制从运行开始到两图完成的一段完整视频，运行中不触碰笔、纸或机械。
8. Ctrl-C可停止、抬笔并释放绕组。中断/断电/释放后原点失效；不要直接继续画。

电脑键盘命令通过Thonny Shell输入，不需要摇杆、OLED或超声波模块。

## 重新生成与验证（在电脑，不在ESP32）

需要Python 3以及 `ezdxf`、`numpy`、`matplotlib`、`shapely`。工作区现有环境已具备这些依赖。

```bash
python3 生成图纸.py
python3 验证/检查程序.py
```

生成器检查板材边界、实际轮廓间距、孔位是否在零件内、Layer 0和DXF审计。程序验证检查双轴插补、同心几何、闭合、软限位、抬笔、超时、中断、空走与名义运行时间。所有报告明确区分计算结果和实物验证。

参考机械尺寸来自 [28BYJ-48尺寸图/数据表](https://www.mouser.com/datasheet/2/813/step_motor_5v_28byj48_datasheet-3247591.pdf)，控制接口依据 [MicroPython 1.27 ESP32 PWM](https://docs.micropython.org/en/v1.27.0/esp32/tutorial/pwm.html)。实物与数据表不一致时以实物测量为准。
