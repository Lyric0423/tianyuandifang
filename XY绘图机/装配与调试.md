## 统一坐标与高度

从上面看：X向右，Y远离操作者。A1为左侧160 mm长齿条导轨，齿向左；A2为右侧直导轨。纸固定在桌面，笔在横梁前面。

以下坐标均为**装配坐标，单位mm**，不是板材排版坐标；槽宽和孔位还可查CSV。

| 零件 | 装配位置 |
|---|---|
| A1 | 沿Y放置，外包x=0..24、y=0..160；齿顶x=0，长槽中心x=14，槽端圆心y=18/142 |
| A2 | 沿Y放置，x=136..152、y=0..160；长槽中心x=144 |
| A3/A4 | 横向放置，x=0..156；分别y=0..12与148..160；孔中心x=14/144 |
| 底脚E1～E4 | 中孔分别位于(14,6)、(144,6)、(14,154)、(144,154) |
| B1 | 横向放置，x=0..156；其前缘Y位置用变量b表示；左、右两组导销均在y=b+7、b+25 |
| B2 | 放到B1上表面，左下角(-38,b-8)，外包到x=18；两孔与B1左侧Y导销孔对齐 |
| C1 | 若笔尖横坐标为c，左下角(c-23,b-24)；笔孔中心(c,b-14)；X导销中心(c-10,b+16)、(c+10,b+16) |
| C2/C3 | 分别贴在C1两个X导销孔的正下方，10×12 mm的孔中心与导销孔对齐；两结合面再垫约0.30 mm固定胶带；只贴在C1上，不能粘到B1 |
| D1 | 上导向孔与C1笔孔同轴，M3立柱穿过C1笔孔两侧的孔，孔中心横向相距18 mm |

按板厚2.75 mm的初始标高：连接条下表面z=27.25；导轨下表面z=30；B1下表面z=32.75；B2及滑垫C2/C3下表面z=35.50；C1下表面z≈38.55；D1下表面z≈59。移动件靠自重落在支承面上，不能靠拧松螺母让它悬空。螺母约0.2 mm的留隙是下方防脱限位间隙。板厚不同，按实际厚度叠加重算，并以滑动顺畅和齿轮同层为准。

**C2/C3及其约0.30 mm固定胶带垫层不能省略。** 滑垫抬高一层，胶带使C1再高于B2约0.30 mm，避免两块板贴住刮擦；胶带只贴在C1/滑垫的固定结合面，不贴滑动面。C1四个边缘缺口分别在横梁局部Y=7、25附近，用来通过Y导销螺丝头。文件抽查按直径6 mm的头部包络；实物头径过大时需改缺口或选小头螺栓再运行。

## 装配顺序

1. **识别并检查孔。** 按编号排版图收齐零件。用Q1试槽宽、双扁轴孔。轴孔应能稳固套轴、无明显晃动，不要用蛮力胀裂亚克力。正式齿轮不合适时使用第二次切割机会改孔。
2. **装底架。** 四根M3×40从底脚向上穿，在立柱上用螺母托住A3/A4；A1/A2叠在连接条上。同一个角的三件共用一根立柱，调到两根导轨平行且同高，再锁紧固定螺母。用少量胶带固定底脚到桌面，避免底架在绘制中走动。
3. **放好纸。** A4普通纸铺在底架下，四角用胶带贴在桌面。目标图形所在区域约为装配坐标x=40..120、y=11..91，避免胶带、折痕和脚垫进入此区域。
4. **装B1与B2。** B2叠在B1左端，两孔与B1的左侧两孔对齐。B2/B1接触面少量胶固定，避开下方导轨与槽。左侧两根Y导销从B2、B1穿过A1槽；右侧两根从B1穿过A2槽。每根销下方两只螺母互锁，使导轨与移动件之间能滑动。螺母不能把移动件夹死。
5. **检查Y空载。** 断电手推横梁，走完整段，不应扭斜或卡住。两根导轨相距130 mm（槽中心距），若不平行，先调底架，不要靠电机硬拉。
6. **装Y电机与G1。** Y电机竖放在B2上，输出轴朝下；壳体中心比轴心再向左偏约8 mm。安装耳穿B2的两条横向长孔。G1位于A1板厚中间高度，齿轮端面不能蹭B1、导轨面或螺母。长孔微调左右啮合，留轻微侧隙；原轴双扁位传递扭矩。需要时用胶带形成止退，胶不能流入电机或齿面。
7. **装X笔架。** 把C2/C3固定在C1下表面两个X导销孔处，在每个结合面垫约0.30 mm胶带，待胶完全固定。两根M3销从C1、滑垫穿过B1的X长槽，下面仍用双螺母留隙互锁。C1四个侧缺口应能通过Y导销头；检查左端对B2有约0.30 mm竖向净空，不靠碰磨实现滑动。
8. **装X电机与G2。** X电机直接坐在C1上，轴朝下，壳体中心相对输出轴向后偏8 mm。不要再给它叠一块电机垫板；C2/C3已经提供所需抬高量。G2与B1同层，调两条纵向安装长孔，使啮合顺滑。裸齿轮不应随意在轴上上下窜动。
9. **装笔与D1。** 用两根M3×30立柱把D1撑在C1笔孔上方约20 mm，两孔同轴。笔从两孔穿下，能靠自重缓慢滑动，不能明显横摆。D2装在笔架上方、舵盘可托起的高度；D3在上导向环附近作为笔身止挡。用胶带止挡固定两环与笔身，不把笔粘死在导向孔里。
10. **装舵机。** SG90侧卧在C1前部、笔的右侧，输出轴水平指向笔；舵盘在竖直平面内转动。用C1前部绑带槽穿橡皮筋/胶带，再少量热熔胶定位。舵盘从下方托D2，抬笔约3 mm；放下时离开D2，由自重/轻微橡皮筋压力落笔。调整到舵盘和笔杆不相撞，也不在落笔时持续向下硬压。
11. **整理走线。** Y电机线要覆盖横梁的Y行程；X电机与舵机线需要同时覆盖X、Y行程。在线束入口留松弛弧圈，在固定端做胶带固定。断电手推全行程，确认线不会被齿轮卷入、不会拉住笔架。

滑销可用普通M3螺杆，但螺纹直接滑动的阻力和磨损会比光轴大；本设计通过低速、小行程来使用它。遇到卡顿先处理槽口、平行度、螺母间隙和笔压，不能只提高电流或加速。清理切割保护膜、毛边与碎屑后再试滑，不把胶带接缝贴在运行的齿面上。

## 接线

按驱动板IN1到IN4顺序接，电机五线插头直接插相应驱动板。下表针对经典ESP32，若是ESP32-S3/C3等其他板卡必须重新核对可用GPIO。

| 模块 | 端子 | ESP32/电源 |
|---|---|---|
| X驱动板 | IN1、IN2、IN3、IN4 | 16、17、18、19 |
| Y驱动板 | IN1、IN2、IN3、IN4 | 21、22、23、25 |
| 两块驱动板 | + / VCC、− / GND | 外接5V正、外接5V负（核对丝印） |
| SG90 | 橙/黄信号 | GPIO26 |
| SG90 | 红、棕/黑 | 外接5V正、外接5V负 |
| ESP32 | GND | 外接5V负，共地 |
| ESP32 | USB | 电脑USB，运行Thonny |

外接5V只给驱动板和舵机，不连接ESP32的3V3，也不额外回接USB供电中的VIN/5V。这里GPIO只控制驱动板，不直接连接绕组。先拔电接线。拆下旧OLED、TM1638、超声波与雷达接线，避免同一GPIO接了不同功能。

## 舵机、方向和原点

第一次先不要把舵盘托笔机构接上。运行 `main.py` 后在Thonny Shell输入 `servo 1200`、`servo 1600`，观察摆动。按实际安装调整 `config.py` 中两个脉宽，确认 `up` 真正抬笔、`down` 能落纸而不顶死。软件仅限制800～2200 us，实际机械允许范围可能更窄。

输入 `jog x 5`，笔应向右；输入 `jog y 5`，笔应远离自己。若方向相反，把对应 `*_DIRECTION` 从1改成-1，重新上传配置并重新运行。一个轴只震动不转时，先检查相序、驱动板五线插头和供电，不是改方向能解决的。

本设计没有限位开关，也不靠堵转找边。正式运行前，在断电且尚未开始录像时把机构放到附近，再用小步点动完成定位：

- X：笔中心c≈35；两根X导销中心x≈25/45。X槽端圆心是24/136，所以左销距左端圆心约1 mm。正式圆最左点在软件x=5，不会使用这1 mm作为画图余量。
- Y：横梁前缘b≈20；两根Y导销的Y坐标为27/45；笔尖Y坐标约6。
- 此时笔尖装配坐标约(35,6)，输入 `zero YES` 把它声明为软件(0,0)。可先在导轨侧贴一小片胶带作定位标记，不要贴进槽内。

软件使用0..90 mm工作范围，X两导销中心相距20 mm，长槽两端圆心相距112 mm，机械名义行程92 mm；Y相应为124−18=106 mm。零点定位不能明显偏离，先慢速空走核对。普通螺帽直径/板材误差仍可能缩小实物有效范围，需要时减小软件工作范围并同步调整图形中心与半径。

## 尺寸标定与正式绘制

设原点后运行 `cal x`，会从(10,10)到(60,10)画一条50 mm水平线；`cal y`会从(10,10)到(10,60)画一条50 mm竖线。测量两端笔迹中心的间距。

```text
新的 X_STEPS_PER_MM = 原值 × 50 / 实测水平长度
新的 Y_STEPS_PER_MM = 原值 × 50 / 实测竖直长度
```

例如水平实测48.5 mm，原值64，则改为64×50/48.5≈65.9794。改配置、重新上传、重启后原点需要重新声明。两轴分别标定，不能一起乘同一个系数。

输入 `dry`：全程抬笔，走完圆、方和返回原点；重点观察缺口是否通过螺帽、笔架是否越界、齿轮是否脱啮。结束后绕组自动释放，原点失效。重新确认原点位置，输入 `zero YES`，最后输入 `draw`。

`draw`顺序：抬笔→到圆起点→画圆→抬笔→到方起点→画四条边→抬笔→回原点→释放。圆和方之间不连线。运行中允许操作电脑，不能手碰笔、纸、亚克力、螺杆或电机来辅助完成。若出问题，Ctrl-C停止并重新调试，从头再录。

默认2 mm/s画线；纸上总长度约451 mm，理论纯画线时间约226秒，另加空移、加减速与抬笔。实测之前以 `验证/程序检查报告.json` 的名义仿真时间作为估算，不当成实际录像时长。程序设570秒运行预算，超时会请求抬笔、释放绕组；电源故障或严重卡死不能靠这个软件预算解决。

## 常见问题

| 现象 | 优先检查 |
|---|---|
| 圆变椭圆 | 两轴steps/mm分别标定；导轨不垂直；某一轴卡住丢步 |
| 圆不闭合、方角回头有空段 | 齿隙、轴孔松动、齿轮上下蹭板、笔压过大 |
| 笔架左端撞东西 | C2/C3是否漏装，C1缺口与Y导销头是否对上，B2是否超出设计x=18 |
| 一边滑另一边卡 | 两根Y轨道不平行/不同高，滑销被螺母夹紧 |
| 画得断断续续 | 纸不平、笔孔夹死、笔环太紧、舵盘放下后仍托着笔 |
| ESP32重启、舵机抽动 | 电机/舵机供电不稳、没有共地，或用ESP32的3V3给电机供电 |
| draw提示原点无效 | 先按定位步骤确认位置，再zero YES；release、重启和中断都会使原点失效 |

第二轮加工优先修复阻碍完成的部分：槽宽、笔孔、轴孔、干涉和啮合。程序里缩小误差参数不能修复明显机械松动。
